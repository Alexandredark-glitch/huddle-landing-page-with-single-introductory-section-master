### 🚀 Key Technical Highlights

- **Fluid Responsive Layouts:** Used CSS Flexbox (`display: flex`) to align content beautifully on widescreen monitors, seamlessly transitioning to a stacked column layout (`flex-direction: column`) on tablet and mobile viewports using precise media queries.
- **Dynamic Asset Swapping:** Managed responsive art direction directly in CSS by swapping out `bg-desktop.svg` and `bg-mobile.svg` within media query breakpoints to maintain visual fidelity.
- **UI Micro-Interactions:** Implemented clean `transition` curves on interactive elements like social links and buttons, utilizing cubic-style translations (`transform: translateY(-10px)`) to provide tangible feedback to the user on hover states.
- **Modern CSS Practices:** Leveraged modern properties like `text-wrap: balance` on heading elements to ensure elegant text line breaks across varying screen dimensions.

### 📖 What I Learned / Practiced
While building this, I refined my understanding of mobile-first asset management, cross-axis alignment using Flexbox, and how to build completely custom pill-shaped components with standard CSS properties without relying on heavy visual assets.
